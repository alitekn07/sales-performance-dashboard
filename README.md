# 📊 Executive Sales Performance Dashboard

## 📌 Project Overview

This project is a professional **Power BI Sales Performance Dashboard** developed to simulate a real-world business intelligence and executive reporting environment.

The dashboard focuses on:

- KPI monitoring
- Regional sales analysis
- Profitability tracking
- Sales representative performance
- Brand-level analysis
- Executive-level reporting

The objective of the project is to transform raw sales data into interactive and actionable business insights using Power BI.

---

# 🎯 Business Objectives

- Monitor overall sales performance
- Track revenue, profit, and cost KPIs
- Compare regional sales distribution
- Analyze brand-level profitability
- Evaluate sales representative performance
- Identify top-performing products and categories
- Support executive-level decision-making

---

# 📂 Dataset Description

Main dataset used:

- `Bolge Satis Dashboard Raw.xlsx`
